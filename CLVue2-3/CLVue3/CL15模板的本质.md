# 模板的本质

## 1. 本质

Vue之所以提供模板的方式，是为了开发者在描述视图的时候更加轻松，Vue在运行的时候本身是不需要什么模板的，他只需要渲染函数，调用渲染函数之后得到的就是虚拟Dom



```vue
<template>
  <div>
    <div>haha</div>    
  </div>
</template>


模板代码是完全可以用js文件写的


export default {
  name: '组件名称',
  props: {},
  render() {
    return h('div', {}, [])
  }
}
```



## 2. 模板的编译

模板其实就是一个字符串，模板编译器在对这个模板进行编译时，是分为几个步骤转换而来的

模板 => 解析器  =>  转换器  =>  生成器   =>  渲染函数  =>  虚拟Dom





## 3. 编译时机

1. 运行时，通常是引入cdn的Vue的开发环境的项目
2. 预编译，预编译是发生在工程化环境下面，是在打包的时候就完成了编译，浏览器拿到的是打包后的代码，是完全没有模板的
